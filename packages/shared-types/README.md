# shared-types

Types TypeScript générés depuis le schéma Supabase
(`supabase gen types typescript`) et partagés entre les trois applications —
non initialisé. Voir la leçon déjà tirée sur MBONPLAN : ce fichier généré
n'est pas régénéré automatiquement sans lien CLI Supabase actif, à
répercuter à la main à chaque évolution du schéma tant que ce lien n'existe
pas.
